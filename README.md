# 🚴‍♂️ Bike Sales Dashboard  

### 📊 Overview
This project focuses on analyzing **bike purchase trends** using demographic and lifestyle data.  
The goal was to uncover insights about which factors influence whether someone purchases a bike.

---

## 🧠 Objective
To clean, organize, and visualize bike sales data using Excel, creating an interactive dashboard that allows users to explore trends by **income, gender, age group, commute distance, and region**.

---

## 📂 Dataset Includes
- **Customer ID**  
- **Marital Status**  
- **Income**  
- **Children**  
- **Education**  
- **Occupation**  
- **Homeowner**  
- **Cars Owned**  
- **Commute Distance**  
- **Region**  
- **Age**  
- **Bike Purchase Status (Yes/No)**  

---

## ⚙️ Process

### 🧹 1. Data Cleaning
- Removed blank values and inconsistencies.  
- Created a new column: **Age Bracket**, categorizing ages into meaningful ranges.  

### 📊 2. Data Analysis
- Built **Pivot Tables** to analyze relationships between:
  - Income, Gender, and Bike Purchase.
  - Commute Distance and Number of Purchased Bikes.  

### 📈 3. Data Visualization
- Created a **Bar Chart** showing **Income vs Gender vs Bike Purchase**.  
- Created a **Line Chart** showing **Commute Distance vs Count of Purchased Bikes**.  

### 🖥️ 4. Dashboard Development
- Combined all visualizations into a single interactive **Excel Dashboard**.  
- Designed clear, color-coded, and easy-to-read visuals for presentation.  

---

## 🧾 Tools Used
- **Microsoft Excel** (Data cleaning, pivot tables, visualization, and dashboard design)

---

## 🔍 Key Insights
- Income and commute distance strongly correlate with bike purchase decisions.  
- Certain **age brackets** and **regions** had higher purchase rates.  
- Gender and homeowner status provided useful segmentation insights.
